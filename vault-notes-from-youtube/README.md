# Savage Vault — Onshape build notes

A hobby project: recreating Adam Savage's miniature (1/12-scale) vault door as
a parametric model in Onshape, following along with the build series on his
YouTube channel. The goal is partly to have something fun on the workbench, and
partly to use a real mechanical assembly — meshing gears, locking pins, a base
plate — as a vehicle for getting deeper into Onshape and CAD fundamentals.

Source video (kickoff):
https://www.youtube.com/watch?v=SiL8IzJSnyU

## How this repo is organized

- **`specs.md`** — single source of truth for every dimension and count. Each
  entry tagged with the source video it came from, so revisions are traceable.
- **`log.md`** — chronological session notes. Newest entries on top. What I
  modeled, what I learned, what I had to revise.
- **`onshape-notes.md`** — Onshape-specific tips: which FeatureScripts to use,
  mate / relation patterns, gotchas as I discover them.
- **`sources/`** — raw notes per video or per reference. The unfiltered
  material that `specs.md` distills.
