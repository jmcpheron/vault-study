as built on the Tested YouTube series. The geometry follows Adam's
dimensions exactly — same materials called out in [`../../specs.md`](../../specs.md),
same gear math, same combination-lock-as-gatekeeper.

## Differences from Adam's build (acknowledged, not "fixes")

- We aren't actually building a physical one in cast iron and brass.
  CAD takes the geometry; the materials are FYI.
- The lapping-plate flatness work, the hand-threading concentricity
  fights, the dividing-plate fixturing — all the rich physical-shop
  knowledge from the videos — exists in the docs as commentary
  ([`docs/build-log.md`](../../docs/build-log.md),
  [`docs/sources.md`](../../docs/sources.md)) but doesn't change the
  CAD.
